Preview

A reader that keeps the repository attached.

Move from files to rendered content, code, themes, and language settings without leaving the document flow.

Repository context stays within reach.

MD Viewer treats Markdown as part of a repository, not as an isolated page.

GitHub repositories
Sign in with GitHub Device Flow, choose an available repository and branch, then move through the file tree from iPhone.
Rich Markdown
Render GFM tables, GitHub Alerts, syntax highlighting, KaTeX, Mermaid diagrams, frontmatter, and internal document links.
Navigation that survives a restart
Return to repository, branch, and file history while local cache keeps recently used content close at hand.
Edit where you read
Update Markdown and README.todo, then submit the change to the repository with an explicit commit.

Make the reader fit the moment.

Change language, color, and offline behavior while the document remains the center of the interface.

  • Three interface languages English, Traditional Chinese, and Spanish update App labels and accessibility metadata.
  • Reader-wide themes Choose from four built-in styles or save a custom accessible color palette.
  • Intentional offline retention Keep downloaded Markdown when needed, or clear the local cache directly from Settings.

Private repositories deserve a clear boundary.

Native authentication, device-local preferences, and on-device translation keep each responsibility in the service that owns it.

GitHub sign-in stays native

OAuth credentials are stored in iOS Keychain and attached to GitHub requests by the native layer.

No intermediary backend

Repository requests travel directly between the App and GitHub.

Translation stays on device

Supported iPhones use Apple Translation, and translated text is kept only for the current App session.
