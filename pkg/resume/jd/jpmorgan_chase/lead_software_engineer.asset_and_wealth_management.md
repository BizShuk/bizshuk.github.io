## 團隊背景 (Team Context)

作為 JPMorganChase 資產與財富管理 (AWM) 部門敏捷小隊的 Lead Software Engineer，負責以安全、穩定且高可擴展的方式構建和交付市場領先的金融技術產品，支撐集團核心業務目標。

## 崗位職責 (Responsibilities)

- 作為 Scrum 團隊的 Lead Developer，主導高價值功能的交付，設定自動化測試、平台框架、SDLC 等最佳實踐，並指導初中階工程師。
- 編寫安全、高質量的生產代碼，進行嚴格的 Code Review 與系統除錯。
- 推動團隊採用企業授權的 AI 輔助軟體工程實踐（AI-assisted code review, refactoring, test acceleration, root-cause analysis），建立輸出驗證與安全編碼標準。
- 深入應用 SDLC 工具鏈與現代自動化工具，主動發現並消除重複性故障，提升系統操作穩定度。
- 主導與外部供應商、新創及內部架構團隊的技術評審，評估架構設計可行性。

## 任職要求 (Requirements)

- 計算機或相關領域學士學位，5 年以上商業應用開發實績。
- 具備 Java 與 React 的商用全棧開發經驗。
- 熟悉 RESTful 微服務設計、現代前端技術生態 (Javascript/Typescript/NodeJS)。
- 熟悉伺服端技術架構 (Spring/Spring Boot, Kafka 訊息流, Maven, JUnit)。
- 熟練掌握關係型資料庫、MongoDB 以及 JVM 效能分析 (Profiling, Heap Dump, Thread Dump, GC Tuning)。
- 深刻理解 CI/CD (Jenkins)、系統彈性 (Resiliency) 與安全規範。
- 具備指導團隊使用 AI 輔助開發工具並審查 AI 輸出正確性與安全性的實績。
