## 崗位職責 (Responsibilities)

- `Android MDM 開發`: 依 Android Enterprise 規範架構並交付自建的 Android MDM.
- `後端與基礎設施`: 以 Java Spring Boot 或 Python 在 Kubernetes 上建置可擴充的後端服務, 確保高可用並編排容器化微服務.
- `即時通訊`: 以 MQTT 或 WebSockets 設計雙向訊息管線, 支援即時指令下發.
- `OEM 技術整合`: 擔任整合的主要技術窗口, 與 OEM BSP 團隊協作解決硬體專屬 SDK 限制與韌體相容性問題.
- `全球部署`: 依業務需求調整系統架構, 兼顧安全防護設計與維運限制.

## 任職要求 (Requirements)

`硬性要求 (Must-have)` — 原文 `Technical Expertise`:

- `Android 精通`: `8 年以上` Android Native (`Kotlin` / `Java`) 開發, 深入掌握 Android Framework 與 `Device Policy Manager (DPM)` 以實現企業級管控.
- `後端熟練度`: 熟練 `Java Spring Boot` 或 `Python` 的伺服端開發, 能設計高併發 RESTful API.
- `Kubernetes 與 Cloud Native`: 具備 K8s 編排, Docker 容器化與生產環境微服務管理的實作經驗.
- `IoT 協定`: 紮實理解 `MQTT` 與 `WebSockets`, 有即時裝置對伺服器通訊架構的實作經驗.
- `技術規格分析`: 能理解複雜技術規格 (Android Enterprise / OEM SDK) 並獨立轉譯為可運作且穩定的程式.

`其他條件 (Other)` — 原文 `Leadership & Soft Skills`:

- `0-to-1 能力`: 展現 pioneer spirit, 能在沒有既有團隊或基礎設施的情況下獨立建置系統.
- `領導經驗`: Tech Lead 或 Engineering Manager 的實績, 能招募與培育初階工程師並定義技術文化.
- `領域適應力`: 高度意願快速學習半導體製造流程, 並將技術方案適配嚴格的廠區與無塵室規範.
- `溝通`: 專業級英語能力, 用於技術文件, 全球協作與對國際硬體供應商的技術談判.
