## 崗位職責 (Responsibilities)

- 帶領工程師團隊, 打造支撐 Apple Store Online 的分散式系統與服務; 這些服務必須可靠, 安全, 且能規模化支撐每日數百萬次的客戶互動.
- 主導安全, 高規模分散式系統的設計與實作, 重點在可靠性, 正確性與效能.
- 與 PM 及設計師深度合作, 形塑藍圖, 及早浮現技術限制, 共同承擔成果, 讓工程與產品作為一個團隊前進.
- 保持動手: 參與系統架構, 程式碼審查與技術問題解決, 成為團隊與夥伴信任的技術聲音; 能在動手寫程式與團隊領導之間分配時間, 也能跳進除錯會議協助解除阻礙.
- 透過 API 設計, 服務可觀測性, 自動化測試, CI/CD 與 secure-by-design 開發等強實務, 推動工程卓越.
- 管理多個併行專案的範圍, 風險與交付, 對各層級利害關係人清楚溝通.
- 招募, 培養並留住高效能工程團隊, 聚焦技術成長與程式碼品質; 透過定期 1:1, 教練與明確的職涯發展投入每個人的成長.

## 我的對位敘事 (Positioning Angle)

這一檔應該列為`本輪第一順位主投`, 優先於 OKX 的 Java 架構師.

`為什麼`: 其他公司的 EM 職缺都用年資或領域當硬門檻 (Stripe 要 3 年 EM, Airwallex 要會計領域), Apple 這一檔把帶人經驗放進 preferred 並明文開放給 `exceptional technical leaders`. 這是唯一一檔在制度上承認 `動手型技術領導者` 路線的職缺, 正好是履歷十二年來的實際樣貌.

`敘事主軸`: 用 preferred 清單當作履歷的目錄. 六項命中 (帶人, 分散式高可用容錯, SQL 與 NoSQL, 可觀測性, 容器化雲原生, 應用安全) 應該逐條在 cover letter 中對應到具體專案, 讓 hiring manager 一眼看到覆蓋率. 開場放 ByteDance 的 `設計全球資料中心冗餘, 使實作與維護成本下降兩個 job grade`, 這句同時證明 scale, 可靠性與商業影響三件事.

`要準備的`: 一是恢復 Java 手感, JD 要求 advance proficiency 且團隊主力是 Java; 二是補電商語彙 (購物車一致性, 庫存超賣, 訂單冪等, 支付回調), 這些問題本質上就是履歷熟悉的分散式一致性問題, 只是換了業務外衣; 三是提前六週恢復刷題節奏.
