## 崗位職責 (Responsibilities)

- `資安架構與設計`: 負責公有雲 (AWS / Azure / GCP), SaaS 服務與 Internet DMZ 網路邊界及系統架構的安全設計, 審查與最佳化.
- `風險評估與管理`: 對既有與新建的 IT 系統與雲端服務執行全面資安風險評估, 辨識潛在威脅並提出可執行的緩解計畫.
- `IT 協作`: 擔任資安部門對 corporate IT, local IT 與 RSO IT 團隊的主要窗口, 確保資安政策與控制無縫落入日常 IT 維運與架構.
- `資安專案管理`: 主導並管理資安相關專案, 涵蓋規劃, 排程, 資源協調與執行, 確保準時且高品質交付.
- `技術諮詢`: 就雲端安全, 網路安全與 SaaS 整合提供專業指引.

`硬性要求 (Must-have)` — 原文 `Required Qualifications`:
