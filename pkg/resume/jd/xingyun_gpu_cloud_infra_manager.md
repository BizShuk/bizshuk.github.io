## 崗位職責

1. **架構規劃與標準制定**: 負責 GPU 算力集群與 AI 基礎設施的整體架構規劃、技術選型與方案落地，覆蓋伺服器硬體、高速網絡、並行存儲及數據中心配套的全鏈路技術評審與標準制定。
2. **雲平臺建設與排程管理**: 主導 GPU 雲服務平臺的建設與迭代，基於 Kubernetes / Slurm 架構搭建算力調度與管理體系，落地多元算力實例、資源隔離、計量計費等核心產品能力，支撐商業化運營。
3. **客戶支援與交付調優**: 面向客戶 AI 業務場景提供全流程技術支持，針對大模型訓練、微調、推理等負載匹配最優算力方案，主導 PoC 驗證、性能調優與項目交付，響應客戶技術需求與方案諮詢。
4. **平臺運營與 SLA 保障**: 負責平臺技術運營與服務質量管理，搭建全鏈路監控告警體系，制定 SLA 標準與故障響應機制，持續優化算力利用率、平臺可用性與運營效率。
5. **供應商管理與項目把控**: 統籌供應商管理與項目交付管控，協同硬體廠商、IDC 服務商等合作伙伴推進項目落地，把控項目進度、技術風險與驗收閉環，建設標準化技術交付體系。
6. **團隊建設與規範沉澱**: 配合業務擴張需求，搭建並帶領基礎設施與運維技術團隊，沉澱技術規範與最佳實踐。
