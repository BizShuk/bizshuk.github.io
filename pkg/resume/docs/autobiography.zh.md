# 自傳 — 劉騰元 (Shuk Liu)

> 工作草稿，2026-09-09。語氣：第一人稱、質樸真誠、不堆砌履歷形容詞。
> 事實依據：`pkg/resume/Resume.md`。兩者應同步更新。

## 一段話的精簡版

我是一個系統人（systems person），花了十二年體悟到：工具本身遠不如背後的 pattern 與本質重要。我打造過線上撲克遊戲、Backend-as-a-Service (BaaS) 平台、醫療資料管線、半導體巨頭的 AI 平台，以及必須在跨區域合規法規約束下運作的資料中心基座。在這些工作之餘，我曾在猶他州的汽車旅館刷過房間、在愛爾蘭與移民官爭取工作權利，也曾在峇里島的礁石海浪中坐錯位置，直到學會閱讀浪湧（swell）的規律。這一路貫穿始終的本能只有一個：找出事物的真實結構，順著它運作，而不是逆著它對抗。

## 第一幕 — 花蓮、中壢，與動手建造的習慣

我在台北長大，大學往東到花蓮的東華大學念資工，隨後北上到中壢的中央大學取得資工碩士。在學生時代對我影響最深的事，從來不是某一門課。當時大學圖書館的電子書搜尋系統既昂貴又緩慢，於是我自己動手做了一套繞過該瓶頸的搜尋工具，每年為圖書館省下超過兩萬美元的授權與維護費。這不是任何人的課堂作業。那時我學到：想讓自己變得有價值，最快的方式就是觀察每個人都在忍受的痛點，並追問「為什麼事情非得是這樣？」

## 第二幕 — 摩押（Moab），那一年我不是工程師

畢業後，我拿著 J-1 簽證前往猶他州的摩押（Moab），在 Motel 6 擔任房務清潔員（housekeeper）。我的同事來自美國、墨西哥、印度、俄羅斯、中國與土耳其。在那個沙漠小鎮裡，我連續換了五個月的床單。

有時人們會把這段經歷視為職涯空檔（gap）。但我把它看作是一次深刻的學習：團隊是一群有著不同預設值的人類所組成，而多數的協作失效從來不是能力或技術問題。從那之後，我所設計的每一個組織架構，受那間汽車旅館的啟發，遠遠多於任何架構書籍。

## 第三幕 — 遊戲、數據，與學會整個閉環

我的第一份正職是在慧邦科技（Gamesofa），一間位於台北、約兩百人的遊戲公司，自研自營麻將、撲克、FPS 與 RPG 等遊戲。我先後交付了 Windows 8 客戶端 App，隨後被轉調至後端團隊，接著又在行銷部門待了一年，負責資料建模與 A/B testing 分析。在同一家公司歷經了三種不同視角。我曾最佳化奧馬哈撲克（Omaha）牌型計算的時間複雜度，也曾與數據分析師坐在一起討論「使用者群體（user group）」的真正定義。

正是從那刻起，我的職涯不再只局限於某種程式語言，而是轉向關注一個完整的閉環（loop）：有人拋出問題，程式碼給出答案，答案改變了產品，而產品又引發了新的問題。

## 第四幕 — 基礎架構，與將 Git 作為唯一真實來源

在卓易科技（Droi Tech），我搭建了 BaaS 平台的 CI/CD 骨幹——涵蓋 Jenkins、Docker、Kubernetes、Terraform 與 Ansible。至今我依然堅持且自豪的架構決定，就是將 Git 確立為環境狀態的唯一真實來源（single source of truth），讓平台的每一次變更都必須經過嚴謹的 code review，而非依賴某個人終端機裡的歷史紀錄。

隨後我選擇離開。我拿著打工度假簽證前往愛爾蘭，卻發現當地的政策無論移民局如何解釋，實際上無法直接銜接長期的工程師正職。我在愛爾蘭待了八十天，接著花了三十天橫跨歐洲旅行，最後回到台灣潛心研讀演算法。

我從不把這段經歷當成彎路。它恰好展現了我做決定的方式：我寧願付出個人代價在現實世界中驗證假設，也不願只坐在辦公桌前空談爭辯。

## 第五幕 — 遠距、高度監管，以及對團隊負責

在 Change Healthcare 的四年半期間，我以遠距方式從台北為這家美國醫療企業服務。我帶領一個五人團隊，參與了三十多場技術面試，並編寫了供其他團隊依賴的共用框架——包含 EventBus、Spring Secret Manager 外掛、事件註解（event annotation）以及 Lambda scaffolding。同時，我也主動發掘並修補那些從未被正式建檔的安全隱憂：以 JWT 簽章的取消訂閱連結、Jenkins Pipeline 中的 KMS 整合，以及 Fortify 安全弱點 backlog 的清償。

醫療領域教會了我一件事：「能跑（it works）」與「被法規允許跑（it is allowed to work）」是兩個截然不同的工程問題，而後者往往更加艱鉅。

## 第六幕 — 台積電（TSMC），與好好離開的勇氣

在台積電，我負責 AI 平台的架構設計，並主導推論層（inference tier）的 MLOps：設計排程器將佇列中的推論任務有效打包至固定的 GPU 資源池中，一旦有任務完成便立即載入下一個任務，確保加速器永不閒置且佇列持續消化。我以 GitOps 推進平台交付，並帶領團隊維持高標準規範：函式限制在 30 行以內、測試涵蓋率保持 90% 以上。

我在那裡待了五個月。當時深感個人與組織文化並不契合，我坦誠提出這點，並在主管與部經理的理解與祝福下離開。我刻意把這段經歷寫進自傳中：比起默默留在一個不適合自己的地方，我更願意誠實面對並講清楚彼此的不合適。

## 第七幕 — 新加坡，以及具有法律形狀的規模化

在新加坡 ByteDance 擔任 Tech Lead 的三年半裡，我也在此取得了永久居民（PR）身分。工作從協調跨團隊將內部與外部服務對齊到新資料中心開始，再於其上承接錢包資料架構路線圖：以法遵期限驅動的歐盟資料遷移、把資料落地與保留期從逐案檢查變成生命週期屬性的 data SDLC、兼顧合規與穩定性的跨資料中心彈性資料通道，以及全球資料中心容災架構，將落地與維護的難度降低了整整兩個職級。我設計了高階任務編排框架（task orchestration framework），並推動跨部門採用區域合規遷移框架。

在這樣的規模下，架構本質上就是組織設計。你無法在兩個系統之間劃清界線的同時，不在兩個團隊之間劃分權責；忽視這一點，正是大規模專案走向失敗的主因。

## 第八幕 — 現在：有意識地選擇獨立打造

自 2026 年年中起，我開始作為獨立 AI 工程師為自己工作。技術橫跨 Gemini、Claude、GPT、Grok、MiniMax、DeepSeek、Qwen 以及 ElevenLabs；我打造了一套 Agent SDK，將所有模型供應商封裝在統一介面之後——因為把產品押寶在單一廠商身上，是我看過太多人輸掉的一場賭局。我獨立交付了數款 iOS 工具 App、一項產品服務、一款衝浪記錄追蹤器，以及兩個語音 Agent 原型（家教與客服），並且全端親自維運個人基礎設施——涵蓋帳號、支付與雲端。

這是我職涯中第一次：架構、程式碼、維運以及所有決策的結果，全都由我一人承擔。這是我經歷過最純粹、最直接的反饋閉環。

## 工作之外的事

我衝浪。在礁石海浪之上，沒有 roadmap 也沒有 backlog，我的資歷也不會替我多划一次水。大海有它自己的 changelog——浪湧週期（swell period）、潮汐推力、礁石暗影——誠實地讀懂它就是全部的遊戲規則。一旦判斷錯誤，代價就是皮肉之痛。

我認為這也是我工作方式最真實的寫照：依據系統當下的真實樣貌去解讀它，而不是盲信文件上的宣稱。坐在對的位置；一旦下浪，毫不猶豫地果斷起乘。
