# Interview questions

What Jean cares about is

1. Is the candidate qualified the position?
2. Would you like to work with the person?

### Knowing tech stack/scope the person have

- Which languages are you most comfortable with? Could you describe your previous learning progress with technique perspective? =>  To know how the person structure his experience in few stages

### Design Pattern

- Usually patterns are divided into two catalogues, structural and behavioral patterns. Could you tell me what you like most/feel more achievement and scenario for implementation?  If the person don’t know design patterns, ask about whether he/she refactor code better before. => To check understanding of design patterns.

### OO

- Please give as more as  terminology you can think of Java (more newly one preferred). Experience before for OO + lambda expression + functional interface (default interface)(consumer, predicator, operator, supplier) + generic

### Refactoring

- If PAAS, ask for what difference between SAAS and PAAS.  If SAAS, ask for whether there is a time/experience refactor existing code if team is focus on business only.

### How to grow applications/technique stack

- What can you think of about growing applications? Start from simple main application.

### Tech Commitment

- What env do you have for your development? Have you tried something making you dev env more convenient/handy? What combination tools do you use in your dev env? => How to know that the person commit themselves in tech?

### Dedication/Focus

- What tech article/document/tutorial do you read in recent? Has you read similar in other languages/architect? What is different? =>How to know that the person can dedicate and be focus on the task/job?

### Architecture

- Has you design some architecture/framework? What is the situation and design? Has you thanked about other way to archive the same result and pros/cons between these two?
- What is next design you’d like to implement?

### Leadership (need more)

- Has you mentor people before? How do you do it(style)?

### Behavior Question

- Morning, afternoon, evening, midnight for coding/working?
- Active person or quite person?
- If rational reason given and no retaliation, will you follow the suggestion? (Too straightforward)
- How do you learn a new thing?
- Fundamental knowledge or handful experience, which r you looking for?
- What do you try to perfect in short term? What is steps?
- Can you tell what tech you learn by yourself and it is out of company scope?

### Advice

- If you know what you want (not only the goal but also how to archive it), it will be more suitable for you. Otherwise, it is a chronic hell environment
