MY.STACK

The actual tools I use daily — no sponsorships, no fluff. Updated when something changes.

01 Terminal & CLI
WezTerm daily

GPU-accelerated terminal. Lua config, multiplexer built-in, ligature support.

wezfurlong.org ↗
fish shell daily

Autosuggestions out of the box. Switched from zsh and never looked back.

fishshell.com ↗
tmux free

Session persistence across SSH. Pairs with WezTerm's native mux for local work.

ripgrep free

Replaced grep everywhere. Respects .gitignore, orders of magnitude faster.

fzf daily

Fuzzy finder for files, git log, shell history. Installed on every machine I touch.

lazygit daily

TUI git client. Interactive rebase without memorising flag combinations.

02 Editor
Neovim daily

LazyVim config. LSP, Telescope, Treesitter. Fast enough that I stopped noticing it.

neovim.io ↗
VS Code free

Fallback for pair programming and when someone else is driving. Also for notebooks.

JetBrains IDEs paid

GoLand for Go, DataGrip for database work. The refactoring tooling is unmatched.

03 Infrastructure
Docker daily

All dev environments in containers. Eliminates "works on my machine" permanently.

k9s daily

TUI for Kubernetes. Browse pods, exec shells, watch logs — no kubectl incantations.

Terraform free

Infrastructure as code. Modules for all shared cloud resources.

1Password CLI paid

Secret injection into shell sessions. No more plaintext .env files in home dir.

04 Apps & Services
Raycast daily

Launcher, clipboard manager, window manager. Replaced Alfred + Magnet + a dozen utilities.

raycast.com ↗
Obsidian free

Local-first notes in Markdown. Sync via iCloud. Graph view only occasionally useful.

Claude daily

Coding assistant, design rubber duck, and occasionally the voice of reason when I'm wrong.

claude.ai ↗
Linear paid

Issue tracking with a keyboard-first interface. Cycles and roadmaps that don't feel painful.

Figma free

For quick mockups and system diagrams. I'm not a designer but Figma lets me pretend.

Spotify paid

Deep work: ambient / post-rock / lo-fi. No-lyrics policy during debugging sessions.

05 Hardware
MacBook Pro M3 daily

16" 36GB. Compiles Go at a speed that makes the fan question its purpose in life.

HHKB Pro Hybrid paid

Topre switches. The tactile thock is either a feature or a personality defect.

LG 27UK850 paid

4K IPS. Not a colour-accurate panel but more than enough for code and dashboards.

Sony WH-1000XM5 paid

ANC for open office days. Also doubles as a social do-not-disturb signal.
