### bizshuk.github.io

`https://bizshuk.github.io` is the main website showing the [index.html](index.html).

`index.html` is the main entry point. It renders a gallery of links driven by [data/gallery.json](data/gallery.json), and from there the user can navigate to [resume.html](resume.html) and the rest of the site.

## Pages
- `index.html` — gallery landing page (entry)
- `resume.html` — digital resume

